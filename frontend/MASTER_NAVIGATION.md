## 🎯 TOP 3 Fragen schnell beantwortet

### Frage 1: "Wie ändere ich die Hero-Section Text?"

**Antwort:** [QUICK_REFERENCE_CHANGES.md](QUICK_REFERENCE_CHANGES.md) → Abschnitt 2

```sql
UPDATE tenants
SET configJson = REPLACE(configJson, '"title": "..."', '"title": "Neuer Text"')
WHERE slug = 'blublu-pizza';
```

Frontend lädt Seite neu → Neuer Text ist da!

---

### Frage 2: "Wie erstelle ich einen neuen Restaurant?"

**Antwort:** [BLUBLU_PIZZA_STEP_BY_STEP.md](BLUBLU_PIZZA_STEP_BY_STEP.md) → Schritt 3

```bash
curl -X POST "http://localhost:5081/api/v1/admin/sites" \
  -H "X-Admin-Key: dev-admin-key" \
  -H "Content-Type: application/json" \
  -d '{...}'
```

Sofort verfügbar unter `http://localhost:5174/?tenant=slug`

---

### Frage 3: "Warum funktioniert mein Restaurant nicht?"

**Antwort:** [TESTING_CHECKLIST.md](TESTING_CHECKLIST.md) → Test durchlaufen

Oder: [DEBUGGING_BLUBLU_PROVISIONING.md](DEBUGGING_BLUBLU_PROVISIONING.md) → "Häufige Fehler"
